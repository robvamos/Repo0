# Contributing

Contributions, corrections, and reproducible ideas are welcome.

## Ground rules

Do not submit:

- credentials or secrets;
- confidential employer/customer information;
- personal data;
- proprietary source code without authorization;
- exploit material targeting real systems;
- content that implies endorsement by OpenAI or an employer.

Prefer small, reviewable contributions with a clear objective and verification steps.

Security-related demos should use intentionally vulnerable, local, synthetic, or otherwise authorized targets.
