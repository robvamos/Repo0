# Workshop — Secure Coding with Codex

## Proposed format

**Title:** Secure Coding with Codex: From Prompt to Reviewed Pull Request  
**Audience:** developers, DevSecOps engineers, security professionals, technical students  
**Duration:** 90–120 minutes

## Learning objectives

Participants should leave able to:

- structure a coding task for an agent;
- constrain scope and permissions;
- inspect the resulting changes;
- identify security-sensitive agent behavior;
- test generated code;
- use Codex as an assistant without delegating accountability.

## Agenda

### 1. Coding agents in practice — 15 min
What an agent can do, where it helps, and where human judgment remains essential.

### 2. From issue to implementation — 20 min
Turn a small requirement into a bounded engineering task.

### 3. Live Codex workflow — 25 min
Inspect repository → propose plan → implement → test → review diff.

### 4. Security review — 20 min
Secrets, dependencies, permissions, injection risks, unsafe commands, validation.

### 5. Human review and pull request — 15 min
Acceptance criteria, tests, review notes, rollback considerations.

### 6. Q&A / community discussion — 15 min

## Demo policy

All demonstrations use public or synthetic projects and data. No employer or customer systems, credentials, internal architecture, or confidential information are used.
