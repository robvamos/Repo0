# Repository Instructions

This repository contains public educational material for secure Codex use.

- Use only public, synthetic, or intentionally created examples.
- Never add employer, customer, production, credential, personal, or security-sensitive information.
- Distinguish completed evidence from plans and simulations.
- Keep demonstrations dependency-light, reproducible, and safe to run locally.
- Review generated changes, run the documented tests, and state residual limitations.
- Keep workstation-specific paths and credentials in ignored local files; version only portable examples.
- Update `project-manifest.json`, `docs/evidence.md`, and `ROADMAP.md` when capabilities or evidence change.
